# 故事清单

清单需要 `title`、`zh_title`、`scenes` 和 `assets`。`scenes` 固定四项，按故事顺序排列。每项包含一幅独立图片、英文叙事短句、中文和一组可以指图回答的双语问题。

```json
{
  "asset": "roll",
  "en": "One apple rolls away.",
  "zh": "一个苹果滚走了。",
  "prompt": {"en": "What happens to one apple?", "zh": "有一个苹果怎么了？"}
}
```

素材可各用一张 PNG，也可从同一张四格拼版用 `crop` 指定 `[左, 上, 右, 下]`。`file` 相对定义素材的清单。`assets_from` 可引用另一个清单的素材。生图时优先选横向 4:3 或相近的画幅，去掉格子里的文字和序号。

输出三张 A4 纵向页，依次是双语四格故事、打乱顺序的无字剪卡、家长复述提示。家长页按剪卡原来的四个位置给出顺序答案。每页按 `-01`、`-02`、`-03` 编号。
