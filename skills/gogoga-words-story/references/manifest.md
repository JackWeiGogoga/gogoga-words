# 故事清单

## 双语四格

默认 `panels` 模式需要 `title`、`zh_title`、`scenes` 和 `assets`。`scenes` 固定四项，按故事顺序排列。每项包含一幅独立图片、英文叙事短句、中文和一组可以指图回答的双语问题。

```json
{
  "asset": "roll",
  "en": "One apple rolls away.",
  "zh": "一个苹果滚走了。",
  "prompt": {"en": "What happens to one apple?", "zh": "有一个苹果怎么了？"}
}
```

素材可各用一张 PNG，也可从同一张四格拼版用 `crop` 指定 `[左, 上, 右, 下]`。`file` 相对定义素材的清单。`assets_from` 可引用另一个清单的素材。生图时优先选横向 4:3 或相近的画幅，去掉格子里的文字和序号。

输出三张 A4 纵向页，依次是双语四格故事、打乱顺序的无字剪卡、家长复述提示。家长页按剪卡原来的四个位置给出顺序答案。每页按 `-01`、`-02`、`-03` 编号。

## 选画法

`style` 控制页面配色，可用 `--style` 覆盖。用对应画法准备 `assets`。省略时沿用 `default`。

| `style` | 插画怎么画 |
| --- | --- |
| `animal-story` | 拟人动物生活绘本。设计原创动物、服装和道具。用清楚的眼神和姿势表达情绪，毛发和衣服留细笔触。围绕一个日常小冲突，逐格呈现动作和情绪的变化。 |
| `engineering` | 工程现场手绘。用铅笔和墨线保留真实部件，水粉色块内带细彩铅笔触。车辆、人员服装和场地跨格一致。场景全景交代位置，近一点的画面突出操作，每格只呈现一步。 |
| `folk-print` | 国风木版淡彩。用略带手工起伏的墨线、少量刻痕、靛蓝、朱砂、石绿和土黄。纹理集中在物体内，页面用干净浅底。用服装、屋舍和场景交代地域与年代，角色和构图按当前故事设计。 |

## 多页绘本

清单里填 `"mode": "book"`，也可在命令行用 `--mode book`。按翻页顺序填写 `scenes`，每项都需要 `asset` 和所选语言的正文。用 `language` 保存语言选项，命令行的 `--language` 优先。

| `language` | 标题字段 | 每页正文 |
| --- | --- | --- |
| `zh`（默认） | `zh_title` | `zh` |
| `en` | `title` | `en` |
| `bilingual` | `zh_title`、`title` | `zh`、`en`，中文在英文上方 |

```json
{
  "mode": "book",
  "style": "folk-print",
  "language": "bilingual",
  "title": "The Boy Who Cried Wolf",
  "zh_title": "狼来了",
  "assets": {"hill": {"file": "hill.png"}},
  "scenes": [{"asset": "hill", "zh": "山坡上，阿禾守着三只羊。", "en": "Ahe looked after three sheep on a hillside."}]
}
```

每项输出一张横向页，单语版为 1440 × 1200，双语版为 1440 × 1320。插画优先用横向 3:2。正文排在插画下方，每种语言最多两行，可用 `\n` 在自然停顿处换行。使用多个角色或同一地点反复出现时，先选定参考插画，在后续生图时沿用角色服装、道具和地标。输出多页时按 `-01`、`-02` 等顺序编号。
