# 宾果清单

可直接传入 `gogoga-words-cards` 用过的 JSON。最少需要 `title`、`zh_title`、`items` 和素材。

| 字段 | 用途 |
| --- | --- |
| `items` | 图词列表。每项包含 `asset` 和 `en`，`zh` 可选。英文词和图块分别保持唯一。 |
| `assets` | 图块定义，例如 `{"bus":{"file":"bus.png"}}`。`crop` 可按 `[左, 上, 右, 下]` 取图。 |
| `assets_from` | 可引用含 `assets` 的其他 JSON，路径相对当前清单。素材路径相对它所在的清单。 |
| `board_size` | 每边格数，接受 2、3 或 4，默认 3。 |
| `board_count` | 棋盘数，接受 1–12，默认 4。 |
| `seed` | 整数种子，默认 0。相同的清单与种子得到同样的排列。 |

可用 `--size`、`--boards`、`--seed` 覆盖清单。词数至少能填满一张棋盘，最多为每板格数乘棋盘张数。每张棋盘一页，末尾是每页最多 16 张的叫词卡。按 `-01`、`-02` 等后缀编号，统一 A4 纵向比例。
