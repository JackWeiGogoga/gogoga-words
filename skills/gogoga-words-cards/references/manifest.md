# 词卡清单

```json
{
  "title": "Fruit",
  "zh_title": "水果",
  "style": "watercolor",
  "pronunciation": "British English · IPA",
  "columns": 5,
  "rows": 4,
  "assets": {"pear": {"file": "pear.png"}},
  "items": [{"asset": "pear", "en": "pear", "ipa": "/peə/", "zh": "梨"}]
}
```

`items` 按从左到右、从上到下的阅读顺序排列。`file` 相对清单路径。如果多幅图在同一张图上，用 `crop` 指定 `[左, 上, 右, 下]` 像素坐标。可用 `assets_from` 指向含 `assets` 的 JSON，例如同一主题的脑图清单，再在 `assets` 中补充个别图块。继承的图块按原清单路径查找。

默认每页五列四行，两项都可以设为 2–5。词汇较长或孩子刚开始认词时，减少每页格数。超出一页时，脚本按 `-01`、`-02` 等后缀输出多张 1080 × 1440 图片。

## 选画法与准备素材

| `style` | 适用场景 | 准备图块 |
| --- | --- | --- |
| `watercolor`（默认） | 水果、植物、自然主题 | 细描线、柔和水彩和少量彩铅颗粒。每幅图保留完整轮廓和裁切留白。 |
| `flat` | 车辆、衣物等密集认词页 | 大色块、干净的深色轮廓、少量必要的细节。统一同类物体的视角、线宽和视觉大小。使用无字透明底插画。 |
| `photo` | 认真实物、日常动作 | 用用户提供的 JPG 或 PNG。让每格只突出一件物品或一个动作，优先选简单背景、主体清晰的照片。 |
| `paper-collage` | 水果、动物、颜色、形状和数数 | 用带可见笔刷纹理的彩绘薄纸剪出不规则边缘，用少量叠色和重叠纸边分清结构。纹理留在剪纸内部，图块外透明，页面为白底。 |

`style` 控制页面配色与标题字体，命令行的 `--style` 可以覆盖它。插画的画法由准备素材时确定，脚本将清单中的图片按比例排入网格。拍摄方向由 EXIF 校正，照片的 `crop` 用校正后看到的像素坐标。渲染前核对每张图和标签的对应关系，尤其是相似物品和单复数。
