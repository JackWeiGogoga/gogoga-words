# 练习清单

```json
{
  "title": "Pear",
  "assets_from": "pear.json",
  "sections": [
    {
      "title": "Colors",
      "images": [{"asset": "green"}, {"asset": "yellow"}, {"asset": "red"}]
    }
  ]
}
```

同一份亲子讲读清单也能直接使用。练习页按 `sections` 的顺序读图，每组可放 1–6 张，打印时按组保留顺序。无字页每页最多五组。贴纸页按首次出现顺序排，每个素材只打印一份，每页最多 16 张。多页输出带 `-01`、`-02` 后缀。

`assets_from` 用于复用其他清单中的 `assets`。也可以在本清单声明 `assets`，图块写成 `{"file":"green.png"}`，可选 `crop` 为 `[左, 上, 右, 下]` 像素坐标。文件路径相对声明它的清单。

## 剪贴配对

`--mode match` 读取同样的 `sections`。每节是一个可辨认的类别，例如 `On Land`，并可加 `"zh_title": "陆上"`。每个图块放进一个类别，每节放 1–6 张。一套底板最多三类，脚本给每类画出对应数量的空格，另页输出同尺寸图卡，按类别交错排列。每套按底板、图卡的顺序输出 `-01`、`-02`，下一套接着编号。底板和图卡用相同缩放比例打印。

## 黑白线稿

`--line-art` 可以和三种练习模式组合。每个用到的素材补一份对应线稿。用黑色轮廓、白色或透明内部，留出能涂色的大块空白。线稿与彩色图可以分别裁切。

```json
{
  "bus": {
    "file": "bus-color.png",
    "line_art": {"file": "bus-outline.png"}
  }
}
```

线稿路径相对该素材所在的清单。可用嵌套的 `crop` 从线稿拼版取图。用彩色模式时读取 `file`，用线稿模式时读取 `line_art` 并使用白底和灰黑文字。缺线稿的素材会在导出前报出名称。
