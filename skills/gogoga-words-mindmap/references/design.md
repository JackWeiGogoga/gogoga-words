# 分支与版式

通常用 5–7 个短英文分支，每个分支回答一个孩子能观察、比较或演示的问题。根据主题挑分支，分支内部尽量用单词和短短语。

| 主题 | 适合的提问线索 |
| --- | --- |
| 水果和食物 | 大小、颜色或种类、外部和切面、口感、怎么吃、在哪里买、怎么生长 |
| 动物 | 家庭或种类、部位、食物、动作、栖息地、成长或与人的关系 |
| 衣物和用品 | 外观、部位、搭配、在哪里用、怎样使用或收纳 |
| 车辆和机械 | 外部可见部件、怎样移动、能做的工作、材料、工作场所、一段典型动作 |
| 场景和现象 | 能看到什么、有哪些种类、代表例子、动作或变化顺序、对比 |

给每个教学词分配一个明确的图像。用同一对象的大小变化表现尺寸，用同一视角表现颜色或状态差异。剖面图只标可准确定位的部位。生长或操作按真实先后排，箭头从左往右。

### 科普图解

按孩子要观察的内容选图，三个画法都可以使用这些结构。讲部件和切面时，科普线描可用少量颜色突出重点。

| 要讲的内容 | 图解结构 |
| --- | --- |
| 车辆或工具的外部部件 | 用完整侧视图配 `callouts`。保留真实比例和部件位置，引线端点落在对应零件上。 |
| 果实、种子或其他内部结构 | 用一张切面图配 `callouts`。同时需要辨认外形时，把完整物体留在主图。 |
| 动作、生长或变化 | 用 `sequence`。在相同视角下拆成能辨认的阶段，选出每一步真正发生变化的部分。 |

## 插画

画布是 1080 × 1440 竖版。主物在左侧约四分之一的宽度内，右侧各分支从上到下排列。较长的流程可以从页面中部铺到右边缘。每个小图保留完整的轮廓和留白。

| 风格 | 插画怎么画 | 页面配色 |
| --- | --- | --- |
| `watercolor`（默认） | 细深褐描线、柔和水彩、克制的彩铅颗粒。参考 [梨样图](../assets/pear-reference.png) 的笔触和色彩。 | [浅白细纹纸](../assets/paper-texture.jpg)、暖黑文字、砖红引线。 |
| `flat` | 粗而干净的深色轮廓、大块实色、少细节，缩小后仍可认。 | 纯白底、深蓝文字、分支用不同颜色。 |
| `diagram` | 蓝灰细线、白色或淡灰填色，保持接近实物的比例。用少量强调色提示部件和动作。 | 纯白底、深蓝文字、蓝灰引线。 |

按所选风格的描述生图。有样图时用它参考笔触和色彩，主体和内容以本次清单为准。要求真实透明底和完整的无字插画。图块多时指定横向网格，逐行列出图块次序并要求清晰间隔。剖面、类别差异和动作步骤要给出可画的外观描述。生成后以实际像素位置选裁切框。

## 排版输入

用 `uv run --script` 运行脚本时，uv 从脚本声明准备 Python 3.10+ 和 Pillow。已有对应环境时，也可直接使用 `python3`。脚本生成 1080 × 1440 自包含 SVG。macOS 可用 `--png` 调用系统的 `sips` 导出 PNG。SVG 优先使用 Chalkboard SE 和 Chalkboard，本机缺少这些字体时会使用替代字体。

```json
{
  "title": "Pear",
  "style": "watercolor",
  "hero": "hero",
  "assets": {
    "hero": {"file": "pear-atlas.png", "crop": [55, 13, 272, 307]},
    "green": {"file": "green.png"},
    "cutaway": {"file": "cutaway.png"},
    "seed": {"file": "seed.png"},
    "sprout": {"file": "sprout.png"}
  },
  "branches": [
    {"title": "Color", "items": [{"asset": "green", "label": "green"}]},
    {"title": "Parts", "layout": "callouts", "asset": "cutaway", "labels": [
      {"text": "seeds", "side": "right", "y": 0.74, "point": [0.54, 0.68]}
    ]},
    {"title": "Grow", "layout": "sequence", "items": [
      {"asset": "seed", "label": "seed", "scale": 0.65},
      {"asset": "sprout", "label": "sprout"}
    ]}
  ]
}
```

- `file` 相对清单路径。可选 `crop` 使用源图像素，依次为左、上、右、下。
- `style` 选用页面配色，命令行的 `--style` 可以覆盖清单设置。新画法的插画由生图或用户素材提供。
- 同一份清单可用 `style_assets` 为各风格补充图块，例如 `"style_assets": {"flat": {"hero": {"file": "hero-flat.png"}}}`。选中风格后，同名图块会用对应版本，其余图块从 `assets` 读取。
- 分支默认是 `items`。给 `sequence` 按实际阅读顺序列图。可用 `scale` 控制小图相对尺寸。
- `callouts` 的 `y` 是标签在分支内的相对高度，`point` 是裁切后图块上的相对坐标，左上为 `[0, 0]`。横向部件图可设 `art_width` 给主体更多宽度，检查两侧标签是否仍在页内。
- 替换部件图后，可在新图块的定义中加 `"callout_points": {"seeds": [0.55, 0.68]}`，以标签文字定位引线端点。其他端点用分支原来的 `point`。
- 各分支默认等高。用正数 `weight` 给标注多的剖面或步骤留更多高度。用短分支标题和短标签保持手机端清晰。
