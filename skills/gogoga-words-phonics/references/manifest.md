# 拼读清单与折页说明

第一版每本聚焦一个短元音。CVC 是一个辅音、一个短元音、一个辅音组成的三音词。本技能使用一份内置词表检查常见的单字母拼读规律。

| 字段 | 内容 |
| --- | --- |
| `title`、`zh_title` | 拼读卡页标题和中文说明。 |
| `vowel` | 单个小写短元音 `a`、`e`、`i`、`o` 或 `u`。 |
| `known_letters` | 孩子已学的单字母音，写成小写字母串，例如 `achmrst`。必须包括所选元音。 |
| `helper_words` | 可选。孩子已经能整体认读的辅助词，写成小写单词数组，例如 `["a","and"]`。只在小书里使用。 |
| `cards` | 3–12 项，每项有 `word` 和 `asset`，例如 `{"word":"cat","asset":"cat"}`。 |
| `pages` | 八页，按实际阅读顺序填。第 1 项是封面，第 8 项是封底。每项有 `text` 和 `asset`，例如 `{"text":"A cat.","asset":"cat"}`。 |
| `assets`、`assets_from` | 可直接给 `{"cat":{"file":"cat.png"}}`，或引用含 `assets` 的其他清单。相对路径以定义素材的清单为准，`crop` 用 `[左, 上, 右, 下]`。 |

脚本逐词检查卡片和小书正文。卡片的词必须在内置词表里，且元音和字母都在本课范围。书页还可用已明确列出的辅助词。检查通过后，再核对句子自然、图文相符。

## 折成八页小书

输出 `-01` 是 A4 纵向拼读卡，`-02` 是 A4 横向小书拼版。拼版上半行倒排，折完后会转到正确方向。

1. 横向单面打印 `-02`，沿所有分格线压出折痕后摊开。
2. 只剪开纸中央横向的实线，保留左右两端和所有虚线。
3. 沿长边对折，让图文朝外。把纸的左右两端往中间推，中央切口会张成菱形。
4. 压平菱形后将页面合拢，让第 1 页做封面，第 8 页做封底。
